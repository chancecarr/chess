Explanation

This is a chess application, written in Java, that allows for chess games to be played live over the internet. Through doing this project I learned Java, networking over HTTP and WebSocket, and application design principles.

By the end of the project, my application included the following:

  1. Documented and tested distributed architecture
  2. Secure management of customer data
  3. Multiple user roles
  4. Enforcement of role restrictions
  5. Session management
  6. Real-time peer interaction over a network
  7. Persistent storage of data
  8. Robust handling of failure cases
